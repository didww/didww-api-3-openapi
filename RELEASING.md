# Releasing a new document

The document is generated by the DIDWW platform's own test suite — nothing in this repository
produces or edits it. Publishing a new version means copying a generated artefact in and recording
which API version it describes.

Do this once a V3 API version becomes the one customers are served, not when it is announced: this
repository tracks the released version, so publishing early would document a surface no API key can
reach yet.

1. **Generate the document** in the platform repository, on the release branch:

   ```bash
   bin/v3_api_openapi   # writes ./v3_api.json
   ```

   The script refuses to write anything unless the whole rswag suite passes, so a document only
   exists if every documented request and response was verified against the live endpoints.

   The version in `info.version` comes from the platform configuration, so generate with the
   **production** configuration — a local `didww_config.yml` carrying a different date for the
   version silently stamps that date all over the document.

2. **Copy it in and derive the YAML** from that same file, so the two formats cannot drift:

   ```bash
   cp /path/to/v3_api.json openapi/v3_api.json
   ruby -rjson -ryaml -e 'File.write("openapi/v3_api.yaml", YAML.dump(JSON.parse(File.read("openapi/v3_api.json")), line_width: -1))'
   ```

3. **Record the version** — copy `info.version` from the document into `VERSION`:

   ```bash
   ruby -rjson -e 'puts JSON.parse(File.read("openapi/v3_api.json")).dig("info", "version")' > VERSION
   ```

4. **Commit, tag with the version date, and push:**

   ```bash
   git commit -am "DIDWW API v3 $(cat VERSION)"
   git tag "$(cat VERSION)"
   git push origin main --follow-tags
   ```

   The tag is what keeps earlier documents reachable — `openapi/` itself only ever holds the current
   version.

CI lints the document and checks that the two formats agree and that `VERSION` matches
`info.version`. It cannot tell whether the document is up to date with the API: that is what the
generating suite is for.
